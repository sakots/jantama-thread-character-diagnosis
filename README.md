# じゃんたまスレ民向けおすすめキャラ診断 — Codex引き継ぎ資料

## 目的

5ch麻雀板「雀魂」スレの会話文化を取り入れた、雀魂キャラクターおすすめ診断Webアプリを開発する。

## 最初に読む順番

1. `AGENTS.md` — Codexへの運用・実装指示
2. `docs/research-status.md` — 調査範囲、根拠の確度、ログの取り扱い
3. `docs/thread-culture.md` — スレ文化、語尾、話題、再現条件
4. `docs/character-profiles.md` — キャラについて現時点で分かっていること
5. `docs/diagnosis-spec.md` — アプリの仕様と診断ロジック案
6. `data/questions.json` — **暫定**の質問案
7. `data/characters.json` — 限定的な初期データ。公式キャラ一覧ではない

## 注意: このパッケージの限界

引き継ぎ部分は過去の会話の記録・指示・要約から再構成した知識ベース。新たに投入されたSiki JSONは `docs/corpus-analysis.md` の方法で集計した。原ログで確認した範囲は `docs/corpus-report.md` に分け、過去の分析要約や診断用仮説と区別する。キャラ人気や好感度を実測した結果として扱わないこと。

ソースの優先度: 元ログ本文 > 本人が確認した分析メモ > 過去の会話要約 > 新規の仮説。

## Codexでの開始方法

このフォルダをGitリポジトリのルートに置いてCodexで開き、`AGENTS.md` に従って最初に仕様とデータ設計を点検する。元ログを投入できる場合は `corpus/`（Git管理対象外を推奨）に追加し、利用条件と個人情報への配慮を確認して再集計する。

## 開発目標

- 10問程度の選択式診断
- 各回答からキャラクターへの相性を算出
- 結果にキャラ名・相性・理由・スレ民風の短評
- スマホ対応
- 根拠のない設定や人気を捏造しない

## アプリの起動

Node.js 22.12以上（または20.19以上）とpnpmを使用する。

```sh
pnpm install
pnpm dev
```

`pnpm test` で自動テスト、`pnpm build` で型検査と本番ビルド、`pnpm preview` でビルド後の確認ができる。

## FTPでの公開

```sh
pnpm build
```

生成された `dist/` の中身（`index.html` と `assets/`）を、FTPで公開したいディレクトリへまとめてアップロードする。例えば `public_html/diagnosis/` に配置した場合は `https://example.com/diagnosis/` で開く。`dist/` フォルダごと配置した場合は、そのフォルダのURLを開く。

JavaScriptとCSSの参照は相対パスにするため、ドメイン直下・任意のサブディレクトリで同じビルドを使える。公開先でNode.jsやPHP、URL書き換えの設定は不要。HTTPまたはHTTPSで配信する静的ホスティングを使用し、フォルダのURLは末尾に `/` を付けるか `index.html` を指定する。

質問・キャラのJSONはビルドに含まれるため、データを更新した場合も `pnpm build` を実行して `dist/` の中身を再アップロードする。`pnpm test:deploy` でビルドとサブディレクトリ配置のアセット参照を検証できる。

## 実装とデータの状態

TypeScript + Reactで10問の回答、戻る・回答変更、傾向集計、再診断、出典説明を実装済み。診断ロジックは `src/domain/`、画面は `src/App.tsx`、質問・キャラ・表示文は `data/` に分ける。データ契約と計算式は `docs/diagnosis-spec.md` を参照。

**現在のキャラ推薦は準備中。** レビュー済みのキャラ属性がないため、回答傾向のみを示す。スコアリング実装の検証にはテスト専用の架空データを使い、公開キャラデータには混ぜない。公式紹介と根拠、診断重みのレビューが揃った候補を追加すると、キャラ推薦と相性度の画面が利用できる。

自動テストと型検査・本番ビルドを確認済み。Edgeで10問の完了、回答の見直し、再診断、キーボード選択を確認し、1280px・390px・320px幅で横スクロールが発生しないことを検証した。キャラ重みの妥当性や人気の検証は含まない。

## 投入ログの再集計

Python 3.10以上を使い、`pnpm analyze:corpus` で前スレ参照とレス言及数を再集計する。解析ロジックの検証は `pnpm test:corpus`。公開レポートは `docs/corpus-report.md`、内部の参照番号・匿名化抜粋・入力ハッシュはGit管理外の `corpus/analysis/` に保存する。

現在の対象は197スレ・197,126レス行。テンプレートや保留投稿等を除く178,997件で集計した。条件と限界は `docs/corpus-analysis.md` に記載している。再集計後の文化資料・キャラ要約・アプリの説明文は、レポートとサンプルを確認して更新する。自動で公式設定や配点に変換しない。
