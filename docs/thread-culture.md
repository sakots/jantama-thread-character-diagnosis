# じゃんたまスレ文化・文体ルール

> 出典の状態: 過去のユーザー指示・分析要約と、投入ログ197スレの再検証。下記の全体像を文化全体の頻度・割合として扱わない。機械集計の範囲は `corpus-report.md` を参照。

## 投入ログで照合した範囲

- 食事、友人戦、「おへへ」、コイト顔文字と丁寧形、コイトと金麦の組み合わせは本文サンプルで存在を確認した。原文や実ユーザーの投稿者情報は公開アプリに転載しない。
- これは存在と用例の確認。全体での頻度、時系列の増減、人気や好感度を確認したものではない。
- 画像・リンク・AA・長文等は保守的に保留しているため、画像文化の頻度や荒らし以外の全投稿数は未確定。

## 全体像

- 麻雀専門議論だけでなく、飯、日常、仕事、天気、ゲーム・アニメ、技術、キャラ話などの雑談が頻繁に交錯する。
- 「麻雀の話はするな」という冗談もある。スレ再現や診断に麻雀の比重を掛けすぎない。
- レスは短く、複数の話題が同時進行し、唐突に割り込むことがある。
- 「>>1 おへへ」などの開幕挨拶・おへへ系の反応がある。
- 何切る相談、友人戦募集、安価、キャラ話、画像反応などが典型的な素材。

## 言葉遣い

- 語尾の例: `にゃ`、`でち`、`なのです`、`ぽこ`、`モ`、`ですっ…！`。
- **すべての投稿に必ず語尾が付くわけではない**。語尾なしの投稿も増えているというユーザーの指摘を尊重する。
- AA、独自顔文字、キャラクターの話し方が併存する。
- 軽い下ネタも会話文化の一部として存在するが、アプリでは表示コンテキストと年齢層に配慮して過剰にしない。

## コイトの表記（ユーザーが明示した厳守ルール）

- 顔文字: `꒰( ˶ ᷇ 𖥦 ᷆ ˵ )꒰`
- キャラ: コイト（福丸小糸）
- 丁寧形・「〜ですっ…！」「〜ますっ…！」など。
- **顔文字の直後には改行を入れず、同じ行に台詞を続ける**。
- 例: `꒰( ˶ ᷇ 𖥦 ᷆ ˵ )꒰ よろしくお願いしますっ…！`

## 画像・専ブラ文化

- Siki等の専用ブラウザではリンク先画像のサムネイルがインラインで見える想定。
- 画像を言葉で過剰説明せず、参加者が見えている前提で短いリアクションを返す。
- 画像だけの投稿や、画像への短い返答が存在する。
- **サムネイルをテキスト記号の枠で擬似表示しない**（ユーザー希望）。アプリでは必要なら実UIの画像サムネイルとして扱う。

## 荒らしの除外

- 通称「おばさん」と呼ばれた荒らしによるグロ画像、グロAA、破壊的な連投・フラッドは学習および再現対象から除く。
- このラベルは特定の投稿行動に対する識別に限る。一般的な「おばさん」という単語や通常のキャラクター会話は対象外。

## 再現したいレス形式

過去の例: `356 焼き鳥名無しさん(ﾜｯﾁｮｲ 5495-mabk) 10/04(日) 23:37:53.19 ID:lAXMnA2E0`
ただし公開アプリでの創作レスに実在する投稿者ID等を流用しない。

## 診断UIに反映するなら

- 質問の一部を雑談、食事、友人戦、キャラ画像、ゲーム、何切る等に分散。
- 結果短評は「それっぽい」一言に留め、過度なコテコテ語尾を避ける。
- 公式キャラの実際の属性をスレ口調から逆算しない。
