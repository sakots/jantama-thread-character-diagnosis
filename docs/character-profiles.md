# キャラクタープロファイル（確定分と未確定分）

## 大切な区別

この資料は「雀魂の公式キャラ一覧」ではない。過去の学習記録に登場するキャラ・キャラネタを記録するだけであり、ゲーム内の雀士と他作品の登場人物を混同しない。

### かずき（一姫）

- 雀魂に関するキャラとして過去の依頼で何度も登場（例: 一姫の画像、カード化）。
- スレではかずき呼びされる
- status: `known-name-only`

### コイト（福丸小糸）

- スレ文脈で独特の顔文字 `꒰( ˶ ᷇ 𖥦 ᷆ ˵ )꒰` と丁寧形を使用する。
- 顔文字の直後に改行しない。`ですっ…！` `ますっ…！` が典型。
- **コラボキャラなのに先住民的にスレに住み着いている**。
- 金麦を愛飲する。

### でち公（キンウ）

- 語尾は「でち」
- 一人称は「あたち」
- ロリキャラ

### ゆず

- 語尾は「なのだ」「ぽこ」
- レッパンズを率いる

### ヒナモ（雛桃）

- 「なのです」系の語尾
- 一人称は「雛桃」
- 語尾「モ」の特殊ヒナモもいる

## 必要な追加調査

- 雀魂で診断対象とする公式雀士の一覧（実装時点の公式情報）。
- 各雀士の公式プロフィールと確度の高い性格属性。
- スレでの愛称・定番ネタ・実際の文脈（本文サンプルで根拠確認）。
- 診断の属性は「公式設定」「スレでの扱い」「診断用設計値」を別々に保持する。
- キャラの人気ランキングや好感度を確証なく作らない。
